# 動画・GIF一括変換ツール 操作マニュアル

## 1. 概要

`input_video` フォルダ内に配置された動画ファイルを読み込み、元の解像度とフレームレート（FPS）を維持したままGIF形式に変換するPythonスクリプトである。

## 2. 動作環境

* **OS**: Ubuntu 24.04 (WSL2 含む)
* **言語**: Python 3.10 以上
* **主要ライブラリ**: MoviePy 2.0.0 以上
* **外部依存**: FFmpeg

## 3. セットアップ

### 3.1. システムパッケージのインストール

ターミナルで以下のコマンドを実行し、動画処理エンジンであるFFmpegをインストールする。

```bash
sudo apt update && sudo apt install -y ffmpeg

```

### 3.2. 仮想環境の構築とライブラリのインストール

プロジェクトのルートディレクトリで以下のコマンドを実行する。

```bash
# 仮想環境の作成
python3 -m venv venv

# 仮想環境の有効化
source venv/bin/activate

# 依存ライブラリのインストール
pip install moviepy

```

deactivate で仮想環境を終了

## 4. ディレクトリ構成

以下の構成でファイルを配置する。

```
.
├── batch_v2g.py      # 実行スクリプト
├── input_video/      # 変換前の動画ファイルを格納（mp4, mov等）
├── output_gif/       # 変換後のGIFファイルが保存される（自動生成）
└── venv/             # Python仮想環境

```

## 5. 使用方法

1. **動画の準備**: `input_video` フォルダ内に、変換したい動画ファイルを全て投入する。
2. **スクリプトの実行**:
```bash
python mp4togif.py

```


3. **完了の確認**: ターミナルに進捗が表示される。全ての処理が終了後、`output_gif` フォルダを確認する。

## 6. 仕様および注意事項

* **解像度とFPS**: 元動画の値をそのまま継承する。高解像度（4K等）や高フレームレート（60fps等）の動画を変換すると、出力されるGIFのファイルサイズが極めて大きくなる点に注意が必要だ。
* **対応拡張子**: `.mp4`, `.mov`, `.avi`, `.mkv`, `.wmv`, `.flv` を処理対象とする。
* **エラー処理**: 特定のファイルの変換に失敗した場合でも、そのファイルをスキップして次のファイルの処理を継続する。
* **メモリ消費**: 大容量の動画ファイルを多数処理する場合、システムのメモリを大量に消費する可能性がある。フリーズ等の現象が発生する場合は、一度に投入するファイル数を制限することを推奨する。
